龍神白狐 五神タイプ診断 ── 画像の置き場所
==========================================

このフォルダに、以下の名前で PNG を保存してください。
名前は半角英字です。1文字でも違うと表示されません。

  souryu.png    蒼龍（木）… 霞を割って真上へ昇る龍・角と鬣が淡い若竹色
  kouryu.png    紅龍（火）… 正面を向き口から光を放つ龍・鬣と炎が淡い臙脂
  ouryu.png     黄龍（土）… とぐろを巻いて静かに構える龍・胴が淡い山吹
  byakko.png    白狐（金）… 九つの尾を広げた白狐・金の首飾り
  kokuryu.png   黒龍（水）… 水面下へ潜り波紋を残す龍・鱗が淡い藍

  hero.png      TOP画面の御神鏡（任意）
                お好きな1枚を選んでコピーし、hero.png という名前で置いてください。
                置かない場合は「龍」の字が表示されます。

保存のしかた（Windows）
------------------------
1. チャットの画像を右クリック →「名前を付けて画像を保存」
2. 保存先を、このフォルダにする
3. ファイル名を上の表のとおりに直す（拡張子は .png のまま）

画像に文字が入っている場合
--------------------------
「蒼龍（木）」のような文字が画像に焼き込まれているときは、
index.html の CONFIG を次のようにしてください。

  IMAGE_HAS_LABEL: true

  → 御神鏡を300pxに拡大し、画面側のタイプ名は出しません
    （名前が二重に出るのを避けるため）

文字の入っていない「絵だけ」の画像に差し替えた場合は、

  IMAGE_HAS_LABEL: false

  → 御神鏡は250px。画面側に金文字で大きくタイプ名を出します
    こちらの方が見栄えがします（推奨）

注意
----
・ファイル名に日本語・空白・大文字を使わないでください。
  GitHub Pages で公開したときに表示されなくなります。
・画像が無い場合は、自動で漢字の紋章（昇・燿・安・覚・深）に切り替わります。
  壊れて表示されることはありません。
・背景は透過のままで大丈夫です。サイト側で墨色の丸窓を敷いています。
