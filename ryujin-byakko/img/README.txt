龍神白狐 五神タイプ診断 ── 画像について
========================================

配置済みです。追加作業は不要です。

  souryu.webp / .png    蒼龍（木）
  kouryu.webp / .png    紅龍（火）
  ouryu.webp  / .png    黄龍（土）
  byakko.webp / .png    白狐（金）
  kokuryu.webp/ .png    黒龍（水）

  hero-banner.webp/.png  TOP画（開運診断のバナー）
  ogp.jpg                LINE・SNSで共有したときのプレビュー画像
  qr-*.png               タイプ別のLINE登録用QR
  favicon.ico / icon-*   アイコン

  _original/             いただいた元画像（無加工）
                         先頭のアンダースコアにより、公開サイトには
                         配信されません（ビルドを軽くするため）

いただいた画像に対して行った処理
--------------------------------
1. 透過の市松模様が画像に焼き込まれていたため、実際の透過に変換
   （端から繋がっている部分と、絵に囲まれた閉じた隙間の両方）
2. 表示寸法に合わせて 1254px → 760px に縮小
3. WebPに変換（合計 11.19MB → 約 0.8MB）
   WebPが読めない環境向けに .png も置いてあり、自動で切り替わります

元画像は _original/ にそのまま残してあります。
やり直したい場合はここから再生成できます。

表示のしかた
------------
・結果画面：画像に焼き込まれた「蒼龍（木）」等がタイプ名になります。
  画面側で同じ名前を重ねて出すことはしません。
  （index.html の CONFIG.IMAGE_HAS_LABEL: true）

・TOP画面：まだタイプが決まっていない画面なので、
  下端を霞に溶かして文字が出ないようにしています。
  絵と文字が縦に重なっているため、切り落とさずぼかしています。

・白い絵が和紙の地に沈まないよう、背後に淡い金の光背を敷き、
  輪郭に二重の影を落としています。

差し替えるとき
--------------
同じ名前で上書きするだけです。
.webp と .png の両方を置き換えてください。
片方しか無い場合も、自動で読める方を使います。
