## ① 朝のご挨拶

```
おはようございます。
龍神白狐でございます。

昨日お伝えした三日間の贈りもの、
本日が一日目でございます。

今日お渡しするのは、
「お稲荷さんへのお参りの作法」です。

読んで終わりではなく、
今週のうちに一度、
足を運んでいただきたいのです。
```

## ② なぜ、お稲荷さんなのか

```

お稲荷さんです。

お稲荷さんは「商売繁盛の神様」

本来は稲、つまり
「実り」を司る神様です。

蒔いた種が実る。
動いたことが形になる。

最初に足を運んでいただきたいのが
お稲荷さんである理由です。
```

## ③ 作法・前半｜鳥居から手水まで

```
【一、鳥居の前で一礼する】

くぐる前に、立ち止まって一礼。
これは「お邪魔いたします」の挨拶です。

ここを省く方が、とても多い。
逆に言えば、ここを丁寧にするだけで
参拝の質が変わります。

【二、参道の端を歩く】

真ん中は「正中」といい、
神様の通り道とされています。

左右どちらでも構いません。
端を、ゆっくり歩いてください。

【三、手水舎で清める】

柄杓に水を汲み、
左手 → 右手 → 口をすすぐ → 左手
最後に柄杓を立てて、柄を洗う。

これを一杯の水で行います。
（柄杓がない神社では、
　流水で両手と口を清めます）
```

## ④ 作法・後半｜拝殿から、帰り道まで

```
【四、お賽銭は、そっと入れる】

投げ入れないでください。
金額よりも、置き方です。

【五、二礼二拍手一礼】

深く二回おじぎ
→ 手を二回打つ
→ 願いを伝える
→ 最後に深く一礼

【六、名前と住んでいる場所を名乗る】

「〇〇に住む、〇〇と申します」

これが最も大切です。
名乗らずに願うのは、
名前を言わずに電話をかけるのと同じです。

【七、願う前に、感謝を伝える】

「いつもありがとうございます」を先に。
願いごとは、そのあとで。

【八、鳥居を出たら、振り返って一礼】

「ありがとうございました」の挨拶です。
ここまでが、ひと続きの作法です。
```

## 事実関係について（要確認事項）

**一般的な作法として広く伝えられている内容を書いています。** ①〜⑧はいずれも神社参拝の一般的な作法として定着しているものです。

ただし、以下は**発信前に確認が必要**です。

1. **油揚げのお供えについては、あえて書いていません。**
   お稲荷さんに油揚げを供える風習はありますが、近年は「持ち帰り必須」「お供え禁止」としている神社が多くあります。神社ごとに違うため、読者が困る可能性があります。触れる場合は「その神社の掲示に従ってください」を必ず添えてください。

2. **「稲荷神は一度願うと一生通わないと祟る」という言い伝えがあります。**
   これは根拠のない俗説とされることが多いものです。今回はあえて書いていません。もし触れるなら「よく言われますが、俗説です」と否定する形にしたほうが、かえって信頼されます。

3. **特定の神社名を出す場合は、その神社の公式情報を確認してください。**
   参拝時間・作法・お供えのルールは神社ごとに異なります。

4. **「三万社」という数字**は、稲荷神社の数としてよく挙げられる数字です。発信前に出典をご確認ください。

**運気が上がるという部分は、ブランドとしての教えです。** 作法そのものは事実として書けますが、効果については断定を避けた書き方にしてあります。
